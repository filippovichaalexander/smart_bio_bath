# Подключение компонентов: Wetware + Hardware + Software

Это практическое руководство «от закупки до первого шага на датчике» —
как физически собрать и подключить все компоненты друг к другу
(биоткань, электронику, ПО) в порядке, соответствующем **текущей**
прошивке в этом репозитории. Точные значения пинов и констант всегда
берутся из [`include/Config.h`](../include/Config.h) — если этот файл
изменится, а данное руководство разойдётся с ним, доверяйте коду.
Более подробные материалы по каждой части:

- [`docs/HARDWARE.md`](HARDWARE.md) — электробезопасность, полная схема пинов, усилитель, bring-up чек-лист.
- [`docs/WETWARE.md`](WETWARE.md) — выращивание и подключение Physarum polycephalum.
- [`docs/TESTING.md`](TESTING.md) — что запускать на каждом этапе (без железа / без биоткани / с железом).
- [`README.md`](../README.md) — структура репозитория и быстрый старт.

## 2. Подготовка рабочего пространства

**Инструменты:**
```
- Паяльник (25-40W) + припой с флюсом
- Мультиметр
- Кусачки, плоскогубцы, отвёртки
- Макетная плата (breadboard)
- Провода "папа-папа" / "папа-мама"
- Термоусадочная трубка, изолента
```

**Требования к помещению:** сухое, проветриваемое, с доступом к розетке
220В (для 5В адаптера), плюс отдельное затемнённое место 20-25°C для
выращивания биоткани (Physarum избегает яркого света — держите чашку
Петри подальше от RGB-ленты).

## 3. Software: сборка и заливка прошивки

Весь software-цикл уже реализован в этом репозитории через Docker —
ничего не нужно пересобирать вручную. Все скрипты работают без
локально установленного PlatformIO.

```bash
git clone <адрес вашего форка/репозитория>
cd smart_bio_bath

# 1. Быстрый тест логики без железа (гейт-матчинг, свет) — пару секунд
./scripts/test.sh

# 2. Полная компиляция прошивки под ESP32 — тоже без железа,
#    ловит ошибки пинов/API библиотек до заливки
./scripts/build.sh

# 3. Только когда ESP32 физически подключена по USB:
./scripts/upload.sh     # заливка (PORT=/dev/ttyACM0 ./scripts/upload.sh, если не ttyUSB0)
./scripts/monitor.sh    # серийный монитор, 115200 бод
```

Зависимости прошивки зафиксированы в [`platformio.ini`](../platformio.ini):
`FastLED`, `RTClib`, `kosme/arduinoFFT@^2.0.4` (новый объектный API —
именно с ним написан [`src/StepAnalyzer.cpp`](../src/StepAnalyzer.cpp)),
`DFRobotDFPlayerMini`. Их устанавливать вручную не нужно — PlatformIO
внутри Docker-образа (`docker/Dockerfile`) сделает это сам при первом
запуске.

Пины и константы (`MAX_PROFILES`, `MATCH_THRESHOLD`, `WATER_TIMEOUT_S`
и т.д.) заданы в одном месте — [`include/Config.h`](../include/Config.h) —
и используются всеми модулями прошивки (`src/StepAnalyzer.cpp`,
`src/ProfileManager.cpp`, `src/LightController.cpp`, `src/VoiceEngine.cpp`,
`src/BioAdapter.cpp`, `src/SafetyMonitor.cpp`), собранными вместе в
[`src/main.cpp`](../src/main.cpp).

## 4. Hardware: сборка аппаратной части

⚠️ **Все подключения — только при выключенном питании.**

### 4.1. Таблица пинов (из `include/Config.h`)

| Компонент | Пин ESP32 | Примечание |
|---|---|---|
| Пьезодатчик (сигнал) | GPIO34 (ADC) | Через усилитель AD620/INA128, никогда напрямую |
| Питание усилителя | 3.3V + GND | |
| RGB-лента (DI) | GPIO26 | Через резистор ~470Ω |
| Кнопка "Нет" | GPIO25 | `INPUT_PULLUP`, второй контакт на GND |
| Зуммер | GPIO27 | |
| Электрод стимуляции биоткани | GPIO32 | Через резистор 10кΩ (см. §5) |
| DFPlayer RX | GPIO16 | ESP32 UART2 RX ← DFPlayer TX |
| DFPlayer TX | GPIO17 | ESP32 UART2 TX → DFPlayer RX |
| SU-03T RX | GPIO18 | ESP32 UART1 RX ← SU-03T TX |
| SU-03T TX | GPIO19 | ESP32 UART1 TX → SU-03T RX |
| Микрофон (детектор воды) | GPIO35 (ADC) | |
| SD карта CS | GPIO5 | |
| SD карта MOSI | GPIO23 | |
| SD карта MISO | **GPIO4** | ⚠️ не GPIO19 — конфликтует с SU-03T TX |
| SD карта SCK | **GPIO14** | ⚠️ не GPIO18 — конфликтует с SU-03T RX |
| RTC SDA | GPIO21 | I2C |
| RTC SCL | GPIO22 | I2C |

SD-карта специально переведена на GPIO4/14 вместо стандартных VSPI-пинов
18/19 — иначе она конфликтует с UART голосового модуля SU-03T. Это уже
учтено и в прошивке (`sdSPI.begin(PIN_SD_SCK, PIN_SD_MISO, ...)` в
`src/main.cpp`), и в распиновке выше — подключайте SD именно на 4/14.

### 4.2. Усилитель биосигналов (критично)

Пьезодатчик выдаёт милливольты — ESP32 ADC нужны вольты.
**Никогда не подключайте пьезо напрямую к GPIO34.**

```
[Пьезо +] ──► AD620/INA128 +IN
[Пьезо -] ──► AD620/INA128 -IN
AD620/INA128 Vout ──► RC-фильтр (~50 Гц срез) ──► GPIO34
AD620/INA128 R_G ──► резистор 50-100Ω (усиление ~500-1000x)
```

RC-фильтр для подавления сетевой наводки 50 Гц:
```
Vout ──┬──► R = 10kΩ ──┬──► GPIO34
       └──► C = 0.33µF ─┘   (частота среза ≈ 48 Гц)
```

### 4.3. Порядок физического монтажа

1. **ESP32 отдельно** — на макетку/в корпус, питание 5В, проверить индикатор.
2. **Периферия без биоткани**: RGB-лента (GPIO26), кнопка (GPIO25), зуммер (GPIO27), RTC (GPIO21/22).
3. **SD + DFPlayer**: SD на исправленных пинах 4/14 (см. §4.1), DFPlayer на 16/17. MP3-файлы на SD см. в `docs/HARDWARE.md` (`0001.mp3`…`0013.mp3`).
4. **Голосовой модуль SU-03T**: на 18/19.
5. **Усилитель + датчики**: INA128/AD620 на макетке, пьезо → усилитель → GPIO34, микрофон воды → GPIO35.
6. **Биоткань — последней**, только после того как всё вышеперечисленное проверено без неё (см. §6-7).

## 5. Wetware: подготовка биоткани

### 5.1. Приготовление агаровой среды
1. Нагреть дистиллированную воду до 80-90°C, добавить агар (2-3г на 100мл), помешивая.
2. Довести до кипения, варить 2-3 минуты до полного растворения.
3. Залить в чашку Петри слоем 3-5 мм, дать застыть (~30-40 минут).
4. Положить 3-5 овсяных хлопьев (не быстрого приготовления) на поверхность.

### 5.2. Выращивание Physarum polycephalum
- **День 1-2**: регидратировать склероций на влажной бумаге 2-4 часа, перенести на агар рядом (не поверх) с хлопьями. Накрыть крышкой неплотно, держать в темноте/непрямом свете при 20-25°C.
- **День 3-5**: наблюдать жёлтые вены, растущие к пище; подкладывать свежие хлопья, увлажнять дистиллированной водой при подсыхании.
- **День 6-7**: плазмодий должен покрыть 50-70% чашки — культура готова.

### 5.3. Уход
Ежедневно проверять влажность и подкармливать (3-5 хлопьев каждые 1-2 дня), убирать заплесневевшие. Раз в 7-10 дней пересаживать на свежий агар. Не использовать водопроводную воду (хлор убивает плазмодий), избегать >30°C/<15°C и яркого света.

Это живой организм — в отличие от остального репозитория, его нельзя
`git reset`. Средний срок жизни культуры — от нескольких недель до
пары месяцев, дальше нужно выращивать заново.

## 6. Интеграция Wetware ↔ Hardware ↔ Software

Здесь описано, как физическое подключение электродов превращается в
реакцию прошивки, и наоборот.

**Схема стимуляции** (из `docs/WETWARE.md`):
```
GPIO32 ──[ резистор 10кΩ ]── Электрод 1 (в/у агара, рядом с плазмодием)
GND    ─────────────────────  Электрод 2 (в/у агара)
```
Резистор 10кΩ ограничивает ток, который GPIO может подать в ткань
(~0.33мА) — GPIO-пины ESP32 сами по себе не токоограничены, это
обязательная мера предосторожности. Используйте только серебряную
проволоку или Ag/AgCl — медь/сталь дают токсичные для плазмодия продукты
коррозии. Электроды должны касаться агара рядом с плазмодием, не
протыкая его.

**Что происходит в прошивке ([`src/main.cpp`](../src/main.cpp) →
[`src/BioAdapter.cpp`](../src/BioAdapter.cpp)):**

| Событие в софте | Пин | Импульс | Когда срабатывает |
|---|---|---|---|
| `BioAdapter::punish()` — штраф | GPIO32 HIGH | 200 мс | Нажата кнопка "Нет" (GPIO25 = LOW) |
| `BioAdapter::reward()` — награда | GPIO32 HIGH | 50 мс | Шаг распознан как известный профиль (см. `ProfileManager::findUser`) |

Оба вызова находятся в главном цикле `loop()` — то есть каждое нажатие
кнопки или каждый успешно распознанный шаг сразу отправляет импульс на
электроды. Длительности (200/50 мс) — стартовые значения из исходного
ТЗ, не откалиброванные; при слишком сильной/слабой реакции культуры их
можно поменять прямо в `src/BioAdapter.cpp`.

**Почему биоткань подключается последней:** до этого момента вы
проверяете, что ESP32, свет, кнопка, RTC, SD/DFPlayer и пьезодатчик
работают сами по себе (см. §7). Только убедившись, что `punish pulse`
действительно печатается в серийный монитор при нажатии кнопки, есть
смысл подключать электроды — иначе будет непонятно, ошибка в
электронике или в реакции живой ткани.

**Важная особенность текущей реализации:** профили пользователей
хранятся только в оперативной памяти ESP32 (`ProfileManager` не пишет
их на SD-карту) — при каждой перезагрузке остаётся только профиль
"Host" по умолчанию, а обученные голосом профили теряются. Это не баг
подключения, а известное ограничение текущей прошивки.

## 7. Пошаговый bring-up и тестирование

Каждый шаг — по `./scripts/upload.sh` + `./scripts/monitor.sh` после
соответствующего подключения из §4.3.

1. **Только RGB + кнопка + зуммер.** В логе: `=== Smart Bio-Bathroom ===`
   … `System ready.` (предупреждения `RTC not found!` / `SD card not
   found!` ожидаемы, пока эти модули не подключены). Лента должна
   загореться белым цветом профиля "Host".
2. **+ RTC.** Строка `RTC not found!` должна исчезнуть.
3. **+ SD (на GPIO4/14!) + DFPlayer.** Строка `SD card not found!`
   исчезает, при старте проигрывается `0001.mp3` (приветствие).
4. **+ пьезодатчик через усилитель.** При постукивании — строка вида
   `Step: dur=... amp=... slope=... vib=... interval=... freq=... snr=...`.
   Многократные шаги одного человека дают `Recognized: Host` (или
   `Unknown visitor`, если походка не попадает в порог `MATCH_THRESHOLD`
   из `Config.h`).
5. **Кнопка "Нет".** В логе `BioAdapter: punish pulse ("No" button
   pressed)`, светодиоды не завязаны на неё напрямую — это просто
   импульс на GPIO32.
6. **Только теперь — электроды биоткани** (§6):
   - **Проверка целостности цепи** (ESP32 выключен): мультиметром
     между электродами через резистор 10кΩ — рабочая культура даёт
     от десятков кΩ до нескольких МΩ; обрыв означает плохой контакт
     электрода или culture ещё не "перекрыла" зазор.
   - **Тест импульса**: нажать "Нет", смотреть на культуру в непрямом
     свете — локальное сокращение или изменение текстуры/цвета рядом с
     электродом в течение секунд-минуты. Это проверка "провод достаёт
     до организма", не проверка обучения.
   - **Поведенческий тест (дни, не минуты)**: многократно сочетать
     конкретную походку с `reward()` (правильное распознавание) против
     `punish()` на неправильную — и по дням наблюдать, сдвигается ли
     рост/реакция плазмодия. Это и есть заявленный в ТЗ "адаптивный
     фильтр" — медленный биологический процесс, не разовая реакция на
     кнопку.

## 8. Тестирование голосовых команд (SU-03T)

Триггерные фразы (совпадают буквально с `src/main.cpp`):

| Фраза | Действие |
|---|---|
| `Запомни меня как <Имя>` | Просит 5 шагов, усредняет параметры, создаёт профиль |
| `Мой цвет <синий/красный/зелёный/жёлтый/фиолетовый>` | Меняет цвет текущего распознанного профиля |
| `Удали меня` | Удаляет профиль текущего пользователя |

Ожидаемая реакция: SU-03T распознаёт фразу → `VoiceEngine::say(...)`
печатает `[VOICE] <ключ_фразы>` в серийный монитор и проигрывает
соответствующий трек с SD (маппинг треков — в `docs/HARDWARE.md`).

## 9. Устранение неисправностей

| Проблема | Решение |
|---|---|
| `Serial port not found` при `upload.sh`/`monitor.sh` | Проверьте кабель/порт: `ls -la /dev/ttyUSB* /dev/ttyACM*`; если не `/dev/ttyUSB0` — задайте `PORT=/dev/ttyACM0 ./scripts/upload.sh` |
| Ошибка компиляции в `build.sh` | Обычно рассинхрон версии библиотеки и API в коде — проверьте `platformio.ini` против того, что реально вызывается в `src/*.cpp` |
| RGB не горит | Питание 5V на ленту, DI → GPIO26 через резистор |
| Нет звука DFPlayer | SD отформатирована в FAT32, файлы лежат в `MP3/0001.mp3`… (не в корне) |
| SU-03T не отвечает | Не перепутаны RX/TX (TX модуля → RX ESP и наоборот) |
| `RTC not found!` не пропадает | Проверьте SDA/SCL (GPIO21/22), подтяжку на 3.3V |
| Все — "Unknown visitor" | Порог `MATCH_THRESHOLD` в `include/Config.h` (0.3 по умолчанию) может быть слишком строгим для вашего датчика/усилителя; также порог самого детектора шага (`detectStepStart`, литерал `100` в `src/StepAnalyzer.cpp`) не вынесен в `Config.h` — менять прямо в коде |
| Профили "пропадают" после перезагрузки | Ожидаемое поведение — профили только в RAM, SD используется лишь для MP3 (см. §6) |
| Плазмодий не растёт / плесень | Температура 20-25°C, влажность, стерильные инструменты при пересадке |
| Нет реакции на стимуляцию | Увеличить длительность импульса в `src/BioAdapter.cpp` (сейчас 200/50 мс) |
| Электроды окисляются | Только серебряная проволока или Ag/AgCl, не медь/сталь |
